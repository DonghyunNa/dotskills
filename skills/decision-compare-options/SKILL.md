# decision-compare-options

## 무엇을 하는가

후보 옵션 2개 이상을 받아 **같은 축으로 평가한 매트릭스 + 추천 + 조건부 대안** 을 출력한다. 매트릭스로 끝나지 않고 *결정* 까지 간다.

## 기본 5축

| 축 | 측정 |
|---|---|
| **효과** | 목표 충족도 (높/중/낮) |
| **시간** | 1주 / 1달 / 분기 / 반기+ |
| **리스크** | 실패 가능성 또는 prod 영향 (높/중/낮) |
| **의존** | 외부 팀·툴·예산 필요 여부 |
| **되돌리기** | 망쳤을 때 롤백 비용 (저/중/고) |

축은 *상황에 맞게* 교체·추가 가능. **단 모든 옵션에 정확히 같은 축 적용** — 옵션마다 다른 기준으로 평가하면 비교 불가.

## 작업 절차

1. **옵션 입력 받기** — 2개 이상. 1개면 비교 의미 없으니 본 스킬 호출 거절
2. **축 선택** — 기본 5축 그대로 가거나, 상황에 맞춰 1~2개 교체
3. **각 옵션을 *같은 축* 으로 평가** — 정량 표현(높/중/낮 등)에는 근거 1줄 같이
4. **매트릭스 한 표로 출력**
5. **추천 1개 + 근거**
6. **조건부 대안** — "X 정보가 바뀌면 옵션 Y 가 더 적합" 으로 결정의 *전제* 노출

## 출력 템플릿

```markdown
## 옵션 비교

### 옵션 A: <이름>
<한 줄 설명>

### 옵션 B: <이름>
<한 줄 설명>

### 옵션 C: <이름>
<한 줄 설명>

## 매트릭스

| 옵션 | 효과 | 시간 | 리스크 | 의존 | 되돌리기 |
|---|---|---|---|---|---|
| A | 높 (이유) | 분기 (이유) | 중 (이유) | 데이터팀 | 중 |
| B | 중 | 1달 | 낮 | 없음 | 저 |
| C | 높 | 반기+ | 높 | 보안팀 | 고 |

## 추천: 옵션 <X>

근거:
- <축 기반 1~2 포인트>
- <제약·우선순위와의 정합성>

## 다른 옵션이 더 적합해지는 조건

- 옵션 Y 가 우세: <어떤 정보·제약이 바뀌면>
- 옵션 Z 가 우세: <…>
```

## 안티 패턴

- ❌ 옵션마다 *다른 축* 사용 — 비교 불가능
- ❌ 매트릭스만 내고 추천 안 함 — 의사결정 안 도움
- ❌ "둘 다 좋다" — 결정 회피
- ❌ 정량 표현(높/중/낮)을 *느낌* 으로 채움 — 각 칸에 근거 한 줄
- ❌ 조건부 대안 생략 — 미래 정보 변화에 대응 불가
- ❌ 옵션 5개+ 다 비교 — 큐레이션 안 한 것. 미리 3~4개로 좁힐 것
